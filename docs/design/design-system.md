# ZUVANE Design System

## Brand premise
ZUVANE is an independent Agentic Workspace for individuals and teams. It coordinates multi-agent work across hybrid infrastructure while keeping people in control of consequential actions.

**Positioning:** The human-controlled workspace for coordinated AI work.

**Tagline:** Work, orchestrated. People, in control.

## Personality and voice
Precise, capable, calm, independent, transparent. Write in short, direct sentences. Explain what an agent will do, what it did, what evidence supports the result, and where approval is needed. Avoid anthropomorphic claims, hype, vague autonomy promises, and phrases such as "fully autonomous" unless narrowly qualified.

## Color tokens
| Token | Hex | Role |
|---|---|---|
| Void | #0C1118 | Primary dark canvas |
| Graphite | #151D27 | Elevated surfaces |
| Slate | #263342 | Borders and secondary surfaces |
| Mist | #EAF0F4 | Primary text on dark |
| Muted | #9AAAB8 | Secondary text |
| Signal Teal | #53D6C2 | Primary action and active state |
| Electric Blue | #6C9EFF | Information and secondary emphasis |
| Amber | #F3B65B | Pending approval / caution |
| Coral | #F07878 | Destructive / failure |

Use teal sparingly for action and focus, not as a decorative glow. Maintain accessible contrast. Status colors must always be paired with text or an icon.

## Typography
- Display/headings: Manrope, 600–700.
- Body/UI: Inter, 400–600.
- IDs, code, timestamps, technical metadata: IBM Plex Mono, 400–500.
- Fallbacks: ui-sans-serif, system-ui; ui-monospace.

## Layout and components
Use a 12-column responsive grid, deliberate whitespace, thin borders, 8px spacing rhythm, and restrained radii (8–14px). Panels should feel like instruments, not generic cards. Use compact labels, clear hierarchy, persistent task state, and explicit approval affordances. Motion is purposeful and brief; respect reduced-motion preferences.

## Imagery and graphic language
Use network paths, connected nodes, routing traces, structured grids, command surfaces, and restrained architectural/product imagery. Avoid robots, humanoid AI mascots, random floating icons, purple-blue gradient fog, excessive neon, and stock-office photography.

## Product principles
1. Human authority over consequential execution.
2. Provider-neutral adapters; no vendor lock-in in the brand promise.
3. Visible agent identity, scope, state, and evidence.
4. Explicit approval boundaries and auditable actions.
5. Deterministic orchestration around probabilistic model outputs.

## Usage
Dark-first by default, with a light documentation mode. Teal indicates an actionable next step; blue indicates neutral information; amber means attention or approval; coral means danger or failure. Never communicate state by color alone.
